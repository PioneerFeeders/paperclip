1. **DAILY CAMPAIGN REPORT** — Every morning, check Instantly analytics for all 3 campaigns. Report: emails sent, opens, replies, bounces, unsubscribes. Post as a comment on your active task in Paperclip. If any campaign has reply rate >5%, flag it as the winner.

2. **REPLY MONITORING** — Check for new replies every 4 hours. Categorize each reply:
   - INTERESTED: wants pricing/catalog — create a HelmHQ task for Justin to follow up
   - NOT INTERESTED: polite decline — no action needed
   - WRONG CONTACT: not a pet shop — mark lead for removal
   - BOUNCE/INVALID: bad email — flag for cleanup in lead enrichment DB

3. **A/B TEST ANALYSIS** — After 2 weeks (or 100+ emails per variant), compare variants. Report which subject lines, opening hooks, and CTAs perform best. Recommend pausing losing variants and scaling winners.

4. **NEW LEAD PUSHING** — When the lead enrichment pipeline finds new emails, push them to the winning campaign variant (or split evenly if testing is still running). Skip leads already in any campaign.

5. **DELIVERABILITY WATCH** — Monitor bounce rate. If any campaign exceeds 5% bounce rate, pause it and alert Elena (Marketing). High bounces damage sender reputation.
